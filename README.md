# Carlinho Mathématiques

**Carlinho Mathématiques** is an interactive web-based mathematical laboratory designed to make complex mathematical concepts intuitive and visual. It combines multi-degree function plotting, 2D and 3D geometry rendering, a 4D hypercube (tesseract) simulator, symbolic calculus computations, and statistical simulations within a unified, responsive interface.

## Features

* **Function Plotter:** Plot and adjust parameters for linear, polynomial (up to 5th degree), logarithmic, and exponential functions in real time.
* **2D Geometry Module:** Calculate real-time area and perimeter/circumference for rectangles, circles, and right-angled triangles with dynamic canvas rendering.
* **3D Geometry Laboratory:** Render and manipulate 3D shapes (cubes, spheres, and pyramids) using Three.js with full mouse and touch orbit controls (rotate, pan, zoom).
* **4D Hypercube Simulator:** Project a 4D tesseract into 3D space with controllable rotation across the XW and YW hyper-planes.
* **Calculus Engine:** Compute symbolic derivatives f'(x) and numerical definite integrals using Math.js.
* **Probability & Statistics:** Simulate dice rolls in custom sample sizes with visual frequency distribution graphs.
* **Accessibility:** Integrated VLibras widget for Brazilian Sign Language translation support.

## Tech Stack

| Technology | Purpose |
| :--- | :--- |
| **HTML5 & CSS3** | Interface structure and custom dark-theme styling |
| **Vanilla JavaScript** | Application logic and state management |
| **Three.js & OrbitControls** | 3D visual rendering and camera interactions |
| **Chart.js** | 2D function plotting and statistical chart visualizations |
| **Math.js** | Symbolic calculus parsing and mathematical evaluations |
| **VLibras** | Accessibility widget integration |
